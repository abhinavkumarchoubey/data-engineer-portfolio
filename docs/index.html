-- projects

bronze silver gold

Walmart Data Pipeline

End-to-end ETL pipeline ingesting retail transactional data from PostgreSQL via CDC into Databricks, moving it through a full medallion architecture (bronze → silver_technical → silver_business → gold) and tracking slowly-changing dimensions with dbt snapshots.

  • Incremental loading across six source tables using dbt's incremental materialization with timestamp-based change detection — no full refreshes.
  • A wide One-Big-Table model built with Jinja templating, dynamically generating a six-table join from a config dict instead of hand-written SQL.
  • SCD Type 2 dimensions (customers, orders, products) via dbt snapshots, capturing full row-level history.
  • A 10-task Airflow DAG on the TaskFlow API — CDC polling via the Databricks SDK, dbt runs segmented by layer, quality tests set to warn rather than block.
